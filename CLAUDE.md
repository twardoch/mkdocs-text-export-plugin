# CLAUDE.md

Guidance for AI agents working in this repository.

## What this is

`vexy-mkdocs-text-export` is an MkDocs plugin. During a site build it writes a
plain-text (`.txt`) or Markdown (`.md`) twin of every page next to the rendered
`.html`, using the [`html22text`](https://github.com/twardoch/html22text) library.

## Layout

| Path | Role |
|---|---|
| `mkdocs_text_export_plugin/plugin.py` | MkDocs `BasePlugin` subclass; wires the build hooks (`on_config`, `on_nav`, `on_post_page`, `on_post_build`). |
| `mkdocs_text_export_plugin/renderer.py` | `Renderer` — maps plugin options onto `html22text`, loads the theme handler, writes output files. |
| `mkdocs_text_export_plugin/themes/*.py` | Per-theme handlers; each exposes `modify_html(html, href)` to inject the "download as text" link, and `get_stylesheet()`. |
| `mkdocs_text_export_plugin/__version__.py` | Generated by `hatch-vcs` from git tags — gitignored, never edit by hand. |
| `tests/` | pytest: `test_plugin.py` (hooks), `test_themes.py` (handlers), `test_integration.py` (real `mkdocs build`). |
| `docs/` | Jekyll (Just the Docs) documentation site. |

## Build flow

`on_post_page` receives each page's final HTML. It computes the output path and a
`base_url` (so `html22text` can resolve page-relative links), calls
`Renderer.write_txt`, then `Renderer.add_link` to insert the theme's link into the
returned HTML. Theme handler selection: a named handler matching `theme.name`, else
the `generic` fallback; a `theme_handler_path` custom module overrides both.

## Conventions

- Python ≥ 3.12. Version comes from git tags via `hatch-vcs`; there is no manual
  version string.
- Every source file starts with a `this_file:` header.
- `html22text` is a `git+https` dependency and not on PyPI, so PyPI publishing is
  intentionally disabled in `release.yml`. Do not re-enable it until `html22text`
  is published.
